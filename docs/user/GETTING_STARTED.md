# Getting Started with SNOTEL

This guide covers installing the SNOTEL custom integration and adding your first USDA NRCS SNOTEL station to Home Assistant.

## Prerequisites

- Home Assistant 2026.4.0 or newer
- HACS, or access to copy custom integration files manually
- Network access from Home Assistant to `https://wcc.sc.egov.usda.gov/awdbRestApi`
- A SNOTEL station you want to monitor, or coordinates near the area of interest

## Installation

### Via HACS

1. Open HACS in Home Assistant.
2. Go to **Integrations**.
3. Open **Custom repositories** from the three-dot menu.
4. Add `https://github.com/aidanlloydtucker/ha-snotel`.
5. Choose **Integration** as the category.
6. Download **SNOTEL**.
7. Restart Home Assistant.

### Manual Installation

1. Download the latest release from GitHub.
2. Copy `custom_components/snotel/` into your Home Assistant `custom_components/` directory.
3. Restart Home Assistant.

## Add a Station

1. Go to **Settings** → **Devices & Services**.
2. Click **Add Integration**.
3. Search for **SNOTEL**.
4. Choose a setup method.

### Search for a Station

This loads the AWDB station list and shows station names in a dropdown. Select the station you want and submit the form.

### Closest Station to Coordinates

Enter latitude and longitude. The integration compares the coordinates to AWDB station metadata and configures the nearest station with location data. The form defaults to your Home Assistant latitude and longitude.

### Manual Station Triplet

Enter a station triplet directly, for example:

```text
539:CO:SNTL
```

Station triplets are the canonical AWDB station identifiers. The integration validates the triplet before creating the config entry.

## What Gets Created

Each configured station creates one Home Assistant device and five sensors:

| Sensor                           | Description                                         |
| -------------------------------- | --------------------------------------------------- |
| Precip Accumulation (Water Year) | Latest hourly `PREC` value in inches                |
| Snow Depth                       | Latest hourly `SNWD` value in inches                |
| Temperature                      | Latest hourly `TOBS` value in degrees Fahrenheit    |
| Snow Water Equivalent            | Latest hourly `WTEQ` value in inches                |
| Last Updated                     | Timestamp of the most recent value returned by AWDB |

The integration polls hourly. Entity IDs are generated by Home Assistant from the station/device name and entity translation names.

## First Dashboard Card

After setup, add an entities card with the sensors created for your station:

```yaml
type: entities
title: SNOTEL
entities:
  - sensor.example_station_precip_accumulation_water_year
  - sensor.example_station_snow_depth
  - sensor.example_station_temperature
  - sensor.example_station_snow_water_equivalent
  - sensor.example_station_last_updated
```

Replace the example entity IDs with the entity IDs shown in your Home Assistant instance.

## Troubleshooting

### Setup Fails

1. Confirm Home Assistant can reach `wcc.sc.egov.usda.gov`.
2. If using manual setup, confirm the station triplet is valid in AWDB.
3. If using station search, try again after a few minutes in case AWDB is temporarily unavailable.

### Entities Are Unavailable

1. Reload the integration from **Settings** → **Devices & Services**.
2. Check Home Assistant logs for `custom_components.snotel`.
3. Confirm the station currently returns hourly `PREC`, `SNWD`, `TOBS`, or `WTEQ` data.

### Debug Logging

Add this to `configuration.yaml`, restart Home Assistant, and reproduce the issue:

```yaml
logger:
  default: warning
  logs:
    custom_components.snotel: debug
```
